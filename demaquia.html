// démaquia
L'outil repère la signature d'origine que posent ChatGPT, Gemini ou Adobe Firefly, la mention « image générée par IA » qu'ajoute par exemple Meta AI, le prompt (la consigne donnée à l'IA) laissé par Stable Diffusion ou ComfyUI, et les informations plus classiques : appareil photo, date, lieu, auteur.
Retirer l'IA seulement efface uniquement les traces d'IA et garde le reste. Tout retirer efface toutes les informations cachées. Dans les deux cas, l'image elle-même ne change pas.
À savoir : une image sans ces informations n'est pas forcément vraie, une capture d'écran suffit à les effacer. Google cache aussi une marque invisible dans les pixels de ses images (SynthID) : l'outil ne peut ni la voir ni l'enlever.
Pour vérifier qu'une signature d'origine est vraie : contentcredentials.org/verify.
Tout se passe dans votre navigateur : aucune image n'est envoyée sur internet.
